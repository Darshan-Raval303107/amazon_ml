| 3 | 6-digit PIN / 5-digit ZIP extracted from address | Strong locality signal where present. |
| 4 | `country` + name 4-char prefix key | Captures transliteration / OCR noise. |
| 5 | Soundex of first name token | Catches spelling variants within same language. |

### Design Constraints (from observed data)

- **Country is open-set**: France appears only in test. Never hard-code or one-hot country.
- **Transliteration**: Devanagari and romanized forms of same entity exist. Apply NFKD normalization.
- **Legal suffixes**: `pvt ltd`, `private limited`, `pvt. ltd.` must be standardized pre-blocking.
- **Landmark addresses**: PIN code extraction more reliable than full address matching for Indian records.
- **Domain names**: Strip `www.`, `.com`, `.in` before building name keys.
- **Singleton rate**: If high, use conservative (high-precision) threshold to avoid false merges.
